# insights-core-messaging-base

This distribution provides the core `insights-core-messaging` library components: the processing engine, application builder, configuration template handling, base CLI consumers and publishers, local filesystem downloader, common formats, watchers, and shared utilities.

For full documentation, usage examples, and repository-level information, see the [main project README in the GitHub repository](https://github.com/RedHatInsights/insights-core-messaging).
