# insights-core-messaging

This is the all-in-one `insights-core-messaging` distribution. It depends on the base, Kafka, and HTTP distributions, and also includes the RabbitMQ consumer, publisher, and requeuer, plus the S3 downloader.

For full documentation, usage examples, and repository-level information, see the [main project README in the GitHub repository](https://github.com/RedHatInsights/insights-core-messaging).
